```sh

- README 两份：补上 0.4.0 的工作区收藏与三个项目筛选开关
```

## 2. 推主分支


## 3. 打 tag

```sh
cd /home/rivenhong/dsh-toomuch-plugins

VERSION=0.4.0

git tag -a v${VERSION} -m "v${VERSION} — 工作区收藏与项目筛选"
git cat-file -t v${VERSION}    # 期望输出：tag（若是 commit 说明是 lightweight，要删掉重建）
git push origin v${VERSION}
git ls-remote --tags origin | grep v${VERSION}
```

## 4. 发 GitHub Release

正文文件已经备好：`.release-notes-v0.4.0.md`（图片用的是绝对 URL，指向 `v0.4.0` tag，
所以**必须先做完第 3 步**）。

```sh
cd /home/rivenhong/dsh-toomuch-plugins

gh auth status                 # 期望：Logged in to github.com

gh release create v0.4.0 \
  --title "v0.4.0 — 工作区收藏与项目筛选" \
  --notes-file .release-notes-v0.4.0.md \
  --latest

rm -f .release-notes-v0.4.0.md   # 用完即删
```

验证：

```sh
gh release list --limit 5     # v0.4.0 在最上面且为 Latest
gh release view v0.4.0 --web  # 用浏览器看一眼排版与三张图
```

## 5. 发 npm

### 5.1 打包预检

```sh
cd /home/rivenhong/dsh-toomuch-plugins

npm pack --dry-run --registry=https://registry.npmjs.org/
```

期望 12 个文件：`package.json`、`cordis.patch.yml`、`icon.svg`、`LICENSE`、
`README.md`、`README.zh-CN.md`、`src/{index,client,history,favorites}.js`、
`locale/{en,zh}.json` —— **没有**测试、截图、docs。

> 沙箱里 npm 可能报 `EROFS`（`~/.npm/_cacache` 只读），加 `--cache /tmp/npm-cache` 绕开。

### 5.2 登录（**这一步必须你自己在 shell 里做**）

```sh
# 方式 A：交互式（推荐）
npm login --registry=https://registry.npmjs.org/

# 方式 B：Automation token（token 只存在于你的终端，不贴进聊天、不提交进仓库）
npm config set //registry.npmjs.org/:_authToken "<你的 token>"
chmod 600 ~/.npmrc

# 验证
npm whoami --registry=https://registry.npmjs.org/
```

> 本机 `~/.npmrc` 常常把 registry 指到 `registry.npmmirror.com`，而镜像源的 token
> 与 npmjs.org **不通用** —— 所以每条命令都显式带 `--registry=https://registry.npmjs.org/`。

### 5.3 发布

```sh
cd /home/rivenhong/dsh-toomuch-plugins

npm publish --access public --registry=https://registry.npmjs.org/
```

### 5.4 验证

```sh
npm view dsh-toomuch-plugins dist-tags versions repository license \
  --registry=https://registry.npmjs.org/
```

逐项核对：

| 项 | 期望 |
| --- | --- |
| `dist-tags.latest` | `0.4.0` |
| `versions` | 含 `0.4.0` |
| `repository.url` | 指向本仓库（插件市场靠它关联） |
| `license` | MIT |

## 7. 出问题怎么回滚

```sh
# npm：撤回某个版本（72 小时内通常允许，可能要 --force）
npm unpublish dsh-toomuch-plugins@0.4.0 --registry=https://registry.npmjs.org/

# npm：发错了但不想删，把 latest 挪回旧版本
npm dist-tag add dsh-toomuch-plugins@0.3.3 latest --registry=https://registry.npmjs.org/

# GitHub：删掉 Release（tag 可以留着，也可以一起删）
gh release delete v0.4.0
git push origin :refs/tags/v0.4.0
```

已经装到用户机器上的包撤不回，DSH 用户需要手动卸载重装。
