# dsh-toomuch-plugins v0.4.0

**一句话：这个版本给工作区加上了「我的最爱」与三个项目筛选开关 —— 项目太多的时候，只看自己关注的那几个。**

**One line: this release gives the workspace list a "My favorites" star and three project filters — when there are too many projects, you only see the ones you care about.**

> 这次是**功能发布**：在 0.3.3 的「侧栏收起 / 网格显示 / 插件操作记录」之上，加了工作区这一侧的能力。原有功能的行为与安装方式都没变，**没有破坏性改动**，升级即用，不用卸载重装。
>
> This is a **feature release**: on top of 0.3.3's panel collapse / grid display / plugin activity log, it adds the workspace side. Existing behaviour and installation are unchanged — **no breaking changes**, just upgrade.

## Changed / 变更

### 我的最爱：项目右键菜单的第一行

项目行的右键菜单多了一条「我的最爱」，**它在第一行**（排在「重命名」之前）。点一下收藏，点一下取消；菜单里的图标在实心星与空心星之间切换，一眼能看出当前状态。收藏过的项目，侧栏里项目名后面跟一颗**黄色的星**。

收藏记在插件自己的文件里（`~/.dsh/plugins/dsh-toomuch-plugins/favorites.json`），以项目的**绝对路径**为键 —— 所以删掉工作区再把同一个目录加回来，星还在；换浏览器、换机器也在。

![侧栏里带黄星的项目](docs/release-pic/favorite.png)

The project row's context menu gains a 「我的最爱」 entry, **as its first line** (ahead of 重命名). Click to star, click again to unstar; the menu icon switches between a filled and an outline star so the current state is obvious. A starred project shows a **yellow star** after its name in the sidebar.

Stars live in the plugin's own file (`~/.dsh/plugins/dsh-toomuch-plugins/favorites.json`), keyed by the project's **absolute path** — so deleting a workspace and adding the same directory back keeps the star, and the stars follow the DSH home rather than the browser.

### 三个筛选开关：视图选项 → 筛选会话

侧栏「工作区」区右上角的视图选项图标里，「筛选会话」分组末尾多了三个开关：

- **仅显示我的最爱项目**
- **仅显示最近 n 天**（默认 7 天）
- **仅显示最新 m 个项目**（默认 3 个）

选中打勾、不选没有勾；点开关**不会关掉菜单**，可以连着勾两个。不符合条件的项目**整行藏起来**，连同它底下的会话一起藏；平铺视图与搜索结果同样生效。

「最近 / 最新」看的是项目**最后一个会话的活跃时间**，不是项目被加进来多久 —— 一个三个月前注册、昨天还在用的项目，算「最近」。

三个开关按**「与」**组合：同时勾「仅显示我的最爱项目」和「仅显示最近 7 天」，就只剩既收藏、又在这七天里活跃过的项目。工作区树里，符合条件的子项目会把它的**父目录那一行也带出来**，这样子项目在树里不会变成没有父行的孤儿；父目录只当容器，它自己的会话仍然藏着。

![视图选项里的三个筛选开关](docs/release-pic/menu.png)

The view-options icon in the workspace region gains three switches at the end of its 「筛选会话」 group: **only my favorite projects**, **only the last n days** (7 by default), and **only the latest m projects** (3 by default). Each shows a check mark when on and none when off; clicking a switch does not close the menu, so you can turn on two in a row. Projects that do not pass are hidden outright, together with their sessions — the flat view and search results behave the same.

「Recent / latest」 follow each project's **last session activity**, not how long ago the project was added: a project registered three months ago but used yesterday counts as recent.

The three switches combine with **AND**: turning on both "only my favorites" and "only the last 7 days" leaves only the projects that are starred *and* active in the past week. In the nested workspace tree, a qualifying child project brings its **parent directory** along, so the child is never an orphan row; the parent is only a container and its own sessions stay hidden.

### 设置页最上方的「工作区视图选项」

设置 → 内置插件 →「侧栏面板显示」页最上方，是「工作区视图选项」这一组：「仅显示最近」的天数（1–99）与「仅显示最新」的项目数（1–9），下面一行说明「最近 / 最新按项目最后一个会话的活跃时间算」。

![设置页的工作区视图选项](docs/release-pic/setting.png)

The 「侧栏面板显示」 tab in Settings → Built-in plugins now opens with a 「工作区视图选项」 group: the days for 「仅显示最近」 (1–99) and the number of projects for 「仅显示最新」 (1–9), plus a note explaining what recent and latest mean.

## Install / 安装

```sh
# 从 npm 安装（预构建，不需要走构建授权）
dsh plugin --profile web add dsh-toomuch-plugins

# 从 GitHub 安装
dsh plugin --profile web add github:rivenshanghai/dsh-toomuch-plugins
```

装完之后还要在 DSH 的插件设置里**启用它**，然后刷新页面。

Install from npm (prebuilt, no build authorisation needed), then enable it in the plugin settings and refresh the page.

## What it does / 效果

- **平时只看自己关注的项目** —— 收藏几个常用的，勾上「仅显示我的最爱项目」，侧栏一下子清爽了。
- **不用手动整理** —— 项目太多时按「最近 / 最新」自动收敛，最近在用的排前面。
- **收藏跟着 DSH 走** —— 不绑定某个浏览器，换机器、换浏览器都还在。
- **原有功能一个没少** —— 侧栏收起、网格显示、插件操作记录都照旧。

- **Look only at the projects you care about** — star the ones you use and turn on "only my favorite projects".
- **No manual tidying** — "recent / latest" narrow the list automatically, most recently used first.
- **Stars follow the DSH home** — not tied to a browser.
- **Nothing existing was lost** — panel collapse, grid display and the plugin activity log all still work.

## Verify / 验证

装上之后应该看到：

1. 右键一个项目 → 菜单**第一行**是「我的最爱」，图标是空心星；点一下，项目名后面出现一颗黄星。
2. 侧栏「工作区」右上角的视图选项图标 → 「筛选会话」分组末尾多出三个开关，默认都没勾。
3. 勾上「仅显示我的最爱项目」→ 只剩被收藏的项目；再点开关，菜单不关，勾也跟着变。
4. 设置 → 内置插件 →「侧栏面板显示」→ 最上方是「工作区视图选项」，两个数字框分别是 7 与 3。

After installing you should see: the 「我的最爱」 entry as the **first line** of a project's context menu with an outline star; three new switches at the end of the view-options menu's 「筛选会话」 group, all unchecked; turning on "only my favorite projects" leaves just the starred projects; and a 「工作区视图选项」 group at the top of the display settings tab.
